# KK

A typographic monograph on the name Kobus Kennedy, in volumes, that rebuilds
itself once a week.

Live at https://drplce.github.io/kk/

- `src/` holds the page template, the page list and one HTML file per section.
- `python3 build.py` assembles the root pages. The root HTML files are generated.
- `assets/site.css` is the bones; `assets/edition.css` is this week's look.
- `beat-the-beat-1974.mp3` is a 40-second SAfm recording, presenter Rafe Lavine,
  played by the custom player on the home and broadcast pages.
- `EDITIONS.md` logs every edition. `WEEKLY.md` is the procedure the weekly
  routine follows. `CLAUDE.md` is the standing brief.

Pushes to `main` deploy to GitHub Pages. Fonts load from Google Fonts: Bodoni
Moda, Newsreader and Karla.
