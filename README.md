# KK

A single-page site for Kobus Kennedy. Plain HTML and CSS in one file, no build step.

- `index.html` is the whole site.
- `beat-the-beat-1974.mp3` is a 40-second recording from SABC Radio 5, presenter Rafe Lavine, played by the custom player on the page.
- Pushes to `main` deploy to GitHub Pages via `.github/workflows/pages.yml`.
- Live at https://drplce.github.io/kk/

Fonts load from Google Fonts: Bodoni Moda (display), Newsreader (text) and Karla (labels).
